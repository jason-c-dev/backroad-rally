# Documentation

This folder has two parts:

- [The making-of](making-of/README.md) tells how an AI coding agent made this game. It
  starts with an Unreal Engine 5 game and ends with this web version.
- [The technical reference](reference.md) gives the keys, the URL options, the quality
  tiers, the systems in the game and the tools for checks and asset conversion.

All the text is in ASD-STE100 Simplified Technical English. The
[making-of introduction](making-of/README.md#about-this-text) tells what that means.
